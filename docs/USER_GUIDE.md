## 1. เริ่มต้นใช้งาน

### 1.1 เข้าสู่ระบบ

1. เปิดเว็บไซต์ของร้าน
2. กรอกข้อมูล 3 ช่อง:
   - **รหัสร้าน** — รหัสที่ได้รับตอนสมัครร้าน
   - **ชื่อผู้ใช้**
   - **รหัสผ่าน**
3. กด **เข้าสู่ระบบ**
4. หากสำเร็จ ระบบจะพาไปหน้า **แดชบอร์ด**

หากลืมรหัสผ่าน กดลิงก์ **ลืมรหัสผ่าน?** ในหน้าเข้าสู่ระบบ

### 1.2 เมนูหลัก

| เมนู | ใช้ทำอะไร |
|------|-----------|
| แดชบอร์ด | ดูสรุปยอดวันนี้และสถิติร้าน |
| รับซื้อยาง | บันทึกรับซื้อจากสมาชิก |
| ขายสินค้า | บันทึกการขายออกไปบริษัทปลายทาง |
| สต็อกสินค้า | ดูคงเหลือตามประเภทสินค้า |
| ประวัติการรับซื้อ | ค้นหา/ดูรายการรับซื้อย้อนหลัง |
| สมาชิก | เพิ่ม-แก้ไขเจ้าของสวนและคนตัด |
| บริษัทปลายทาง | จัดการรายชื่อบริษัทที่ขายให้ |
| ค่าใช้จ่าย | บันทึกค่าใช้จ่ายร้าน |
| รายงาน | ดูรายงานสรุปและพิมพ์/ส่งออก |

**ตั้งราคา** และ **ตั้งค่าระบบ** เปิดจากเมนูบัญชีผู้ใช้ (มุมบน) ไม่ได้อยู่ในแถบเมนูหลัก

### 1.3 ออกจากระบบ

เปิดเมนูบัญชีผู้ใช้ แล้วเลือกออกจากระบบเมื่อเลิกใช้งาน

---

## 2. สิทธิ์ผู้ใช้

ร้านสามารถมีผู้ใช้หลายคน โดยสิทธิ์แบ่งเป็น:

| สิทธิ์ | ความหมายโดยย่อ |
|--------|----------------|
| **ผู้ชม** | ดูข้อมูลได้อย่างเดียว ไม่แก้ไข |
| **ผู้ใช้งาน** | บันทึกและแก้ไขงานประจำวันได้ เช่น รับซื้อ สมาชิก ราคา |
| **ผู้ดูแล** | สิทธิ์เต็ม รวมจัดการผู้ใช้และตั้งค่าระบบ |

หากกดปุ่มแล้วไม่ทำงาน หรือไม่เห็นเมนูบางอย่าง ให้ถามผู้ดูแลว่ารหัสของคุณเป็นสิทธิ์อะไร

---

## 3. แดชบอร์ด

หน้าแรกหลังเข้าสู่ระบบ ใช้ดูภาพรวมเร็วๆ เช่น:

- สรุปการรับซื้อวันนี้ (แยกตามประเภทสินค้า)
- น้ำหนักวันนี้
- ราคาประกาศวันนี้
- รายการรับซื้อ / ขาย / ค่าใช้จ่ายล่าสุด
- สมาชิกที่มียอดสูง

ใช้แดชบอร์ดเพื่อตรวจว่าวันนี้ตั้งราคาแล้วหรือยัง และยอดรับซื้อไปถึงไหนก่อนปิดร้าน

---

## 4. ตั้งราคาและประเภทสินค้า

ไปที่ **ตั้งราคา** จากเมนูบัญชีผู้ใช้

### 4.1 ประเภทสินค้า

ตัวอย่างประเภทที่ใช้บ่อย: น้ำยางสด, ยางแห้ง, เศษยาง

1. เปิดหน้าตั้งราคา
2. เพิ่มหรือแก้ไขประเภทสินค้าให้ตรงกับที่ร้านรับซื้อจริง
3. บันทึก

ควรตั้งประเภทสินค้าให้ครบก่อนเริ่มรับซื้อในแต่ละวัน

### 4.2 ตั้งราคาประกาศประจำวัน

1. เลือกวันที่
2. เลือกประเภทสินค้า
3. กรอกราคาต่อหน่วย
4. ตั้งเงื่อนไขราคาเพิ่ม/ลดตาม %ยาง (ถ้ามี)
5. บันทึก

ราคาที่ตั้งไว้จะถูกนำไปแนะนำตอนบันทึกรับซื้อ สามารถปรับราคาพิเศษ (โบนัส) ต่อรายการได้ตอนรับซื้อ

### 4.3 ดูประวัติราคา

ในหน้าตั้งราคา สามารถดูประวัติราคาย้อนหลัง เพื่อเทียบวันก่อนหน้าหรือตรวจสอบความถูกต้อง

---

## 5. จัดการสมาชิก

เมนู: **สมาชิก**

### 5.1 เพิ่มสมาชิกใหม่

1. กดปุ่มเพิ่มสมาชิก
2. กรอกข้อมูลหลัก:
   - ชื่อ
   - รหัสสมาชิก (ถ้ามี)
   - กลุ่มสมาชิก (ถ้าใช้)
   - เบอร์โทร / ที่อยู่
   - เลขบัตรประชาชน 13 หลัก (ถ้ากรอก)
   - ธนาคาร / เลขบัญชี
   - ชื่อคนตัด
   - % เจ้าของสวน และ % คนตัด (รวมกันควรครบ 100)
3. บันทึก

### 5.2 แก้ไข / ค้นหาสมาชิก

- ใช้ช่องค้นหาด้านบนเพื่อหาชื่อหรือรหัส
- กดแก้ไขเพื่ออัปเดตข้อมูล
- ดูประวัติการรับซื้อของสมาชิกจากหน้ารายการสมาชิก

### 5.3 ค่าบริการสมาชิก

หากสมาชิกมีค่าบริการประจำ (เช่น ค่าบริการรายเดือน) สามารถตั้งค่าบริการในหน้าสมาชิกได้  
ค่าบริการนี้อาจถูกนำไปหักตอนจ่ายเงินหรือบันทึกพร้อมการรับซื้อตามที่ร้านใช้งาน

---

## 6. รับซื้อยาง

เมนู: **รับซื้อยาง** — งานหลักของหน้าร้าน

### 6.1 ขั้นตอนบันทึกรับซื้อ

1. เลือก **วันที่**
2. ค้นหาและเลือก **สมาชิก**
3. เลือก **ประเภทสินค้า**
4. กรอกน้ำหนัก:
   - **น้ำหนักรวมภาชนะ**
   - **น้ำหนักภาชนะ**
   - ระบบคำนวณ **น้ำหนักสุทธิ** ให้
5. ตรวจ **ราคาต่อหน่วย** (ระบบอาจแนะนำจากราคาประกาศวันนี้)
6. ใส่ **ราคาบวกเพิ่มพิเศษ** ถ้ามี
7. ใส่หมายเหตุถ้าต้องการ
8. กดเพิ่มเข้าตะกร้ารายการ (สามารถเพิ่มหลายรายการในครั้งเดียว)
9. ตรวจยอดรวม แล้วบันทึกรายการ

### 6.2 ค่าบริการตอนรับซื้อ

ในหน้าเดียวกันสามารถสลับไปบันทึกค่าบริการที่เกี่ยวข้องกับรายการได้ (ถ้ามีการใช้งาน)

### 6.3 พิมพ์ใบรับซื้อ (Slip)

หลังบันทึกสำเร็จ สามารถพิมพ์ใบรับซื้อให้สมาชิกได้  
ชื่อร้าน ที่อยู่ และขนาดกระดาษใบเสร็จตั้งได้ที่ **ตั้งค่าระบบ → ใบรับซื้อ (Slip)** โดยผู้ดูแล

### เคล็ดลับหน้าร้าน

- ตั้งราคาประจำวันก่อนเริ่มรับซื้อ
- ตรวจชื่อสมาชิกให้ถูกก่อนบันทึก
- หากน้ำหนักสุทธิติดลบหรือผิดปกติ ให้ตรวจน้ำหนักภาชนะอีกครั้ง
- สามารถใช้คีย์ Enter / ลูกศรเพื่อเลื่อนช่องกรอกได้เร็วขึ้น

---

## 7. ประวัติการรับซื้อ

เมนู: **ประวัติการรับซื้อ**

ใช้เมื่อต้องการ:

- ค้นหารายการย้อนหลัง
- ตรวจยอดของวันใดวันหนึ่ง
- พิมพ์หรือตรวจสอบใบรับซื้ออีกครั้ง
- แก้ไข/ลบรายการที่ผิด (ตามสิทธิ์ที่ได้รับ)

ควรตรวจสอบประวัติทุกสิ้นวันก่อนปิดร้าน

---

## 8. ขายสินค้าและสต็อก

### 8.1 ขายสินค้า

เมนู: **ขายสินค้า**

1. เลือกวันที่
2. เลือกบริษัทปลายทาง (หรือกรอกชื่อบริษัท)
3. เลือกประเภทสินค้า
4. กรอกน้ำหนัก / %ยาง / ราคา
5. เลือกประเภทการขาย (ถ้ามีตัวเลือกในฟอร์ม)
6. เพิ่มค่าใช้จ่ายที่เกี่ยวกับการขายครั้งนั้นได้ (เช่น ค่าขนส่ง) ตามที่ฟอร์มรองรับ
7. ตรวจยอดและกำไรโดยประมาณ แล้วบันทึก

### 8.2 สต็อกสินค้า

เมนู: **สต็อกสินค้า**

- ดูยอดคงเหลือแยกตามประเภทสินค้า
- กดเข้าไปดูรายละเอียดของแต่ละประเภทได้

ใช้คู่กับหน้าขายสินค้าเพื่อเช็กว่ามีของพอขายหรือไม่

---

## 9. บริษัทปลายทาง

เมนู: **บริษัทปลายทาง**

1. เพิ่มชื่อบริษัทที่ร้านขายยางให้เป็นประจำ
2. แก้ไขข้อมูลเมื่อมีการเปลี่ยนชื่อหรือรายละเอียด
3. ตอนบันทึกขายสินค้า สามารถเลือกบริษัทจากรายการนี้ได้เร็วขึ้น

---

## 10. ค่าใช้จ่าย

เมนู: **ค่าใช้จ่าย**

### 10.1 บันทึกค่าใช้จ่ายร้าน

1. เลือกวันที่
2. เลือกหรือพิมพ์หมวดหมู่ เช่น:
   - ค่าน้ำมัน
   - ค่าซ่อมรถ
   - ค่าคนงาน
   - อื่นๆ
3. กรอกจำนวนเงิน
4. ใส่รายละเอียด (ถ้ามี)
5. บันทึก

หน้านี้แสดงสรุปค่าใช้จ่ายวันนี้ เดือนนี้ และค่าเฉลี่ยรายวัน เพื่อให้ผู้ดูแลตรวจค่าใช้จ่ายได้เร็ว

---

## 11. รายงาน

เมนู: **รายงาน**

เลือกแท็บตามสิ่งที่ต้องการดู:

| แท็บ | เนื้อหา |
|------|---------|
| รับซื้อประจำวัน | สรุปยอดรับซื้อรายวัน |
| สรุปการขาย | ยอดขายออก |
| สรุปรายสมาชิก | สมาชิกแต่ละคนมียอดเท่าไร |
| ค่าใช้จ่าย | สรุปค่าใช้จ่ายตามช่วงเวลา |
| กำไร / ขาดทุน | ภาพรวมกำไรขาดทุน |
| กำไร / ขาดทุนต่อกอง | แยกวิเคราะห์รายกอง/กลุ่ม |

### วิธีใช้รายงานทั่วไป

1. เปิดเมนูรายงาน
2. เลือกแท็บ
3. กำหนดช่วงวันที่ / ตัวกรอง
4. กดดูผลลัพธ์
5. พิมพ์หรือส่งออกเมื่อต้องการเก็บเอกสาร

## 12. ตั้งค่าระบบ (แอดมิน)

เปิดจากเมนูบัญชีผู้ใช้ → **ตั้งค่าระบบ**  
เฉพาะ **ผู้ดูแล**

### 12.1 ใบรับซื้อ (Slip)

ตั้งค่าที่ปรากฏบนใบรับซื้อ เช่น:

- ชื่อร้าน / บริษัท
- ที่อยู่
- ขนาดกระดาษที่เครื่องพิมพ์ใช้

ตรวจพิมพ์ทดสอบ 1 ใบหลังเปลี่ยนค่าทุกครั้ง

### 12.2 ผู้ใช้งาน

1. เพิ่มผู้ใช้ใหม่ (ชื่อผู้ใช้, รหัสผ่าน, สิทธิ์)
2. แก้ไขสิทธิ์หรือสถานะเปิด/ปิดการใช้งาน
3. ลบผู้ใช้ที่ไม่ใช้งานแล้ว

หมายเหตุ: ระบบมีจำนวนผู้ใช้สูงสุดต่อร้าน หากถึงขีดจำกัด ต้องลบผู้ใช้เก่าก่อนเพิ่มใหม่

---

## 13. โปรไฟล์ร้านและโหมดมืด

### โปรไฟล์ร้าน

เปิดจากเมนูบัญชีผู้ใช้ → **โปรไฟล์**  
ใช้ดู/จัดการข้อมูลร้านตามที่ระบบแสดง

### โหมดมืด (Dark Mode)

กดปุ่มสลับโหมดมืด/สว่างที่มุมหน้าจอได้ทั้งหน้าเข้าสู่ระบบและหลังเข้าใช้งานแล้ว

---

## 14. คำถามที่พบบ่อย

**ถาม: เข้าสู่ระบบไม่ได้**  
ตอบ: ตรวจรหัสร้าน ชื่อผู้ใช้ และรหัสผ่านให้ครบ หากยังไม่ได้ ให้ใช้ลิงก์ลืมรหัสผ่าน หรือติดต่อผู้ดูแลร้าน

**ถาม: ไม่เห็นปุ่มบันทึกหรือแก้ไม่ได้**  
ตอบ: บัญชีอาจเป็นสิทธิ์ผู้ชม ให้ผู้ดูแลปรับเป็นผู้ใช้งานหรือผู้ดูแล

**ถาม: ราคาตอนรับซื้อไม่ตรง**  
ตอบ: ไปตั้งราคาประกาศประจำวันก่อน หรือปรับราคา/ราคาบวกเพิ่มในรายการนั้นเอง

**ถาม: น้ำหนักสุทธิผิด**  
ตอบ: ตรวจน้ำหนักรวมภาชนะและน้ำหนักภาชนะอีกครั้ง ระบบคำนวณสุทธิให้อัตโนมัติ

**ถาม: พิมพ์ใบรับซื้อแล้วข้อมูลร้านผิด**  
ตอบ: ให้ผู้ดูแลไปตั้งค่าที่ **ตั้งค่าระบบ → ใบรับซื้อ (Slip)**

**ถาม: สมาชิกซ้ำหรือหาไม่เจอ**  
ตอบ: ค้นด้วยชื่อหรือรหัสในหน้าสมาชิก และตรวจว่ายังไม่ได้ปิด/ลบรายการ
