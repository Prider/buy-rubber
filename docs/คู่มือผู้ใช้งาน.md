# คู่มือผู้ใช้งาน Yang Dee

ระบบบริหารจัดการรับซื้อและขายยาง สำหรับจุดรับซื้อที่ต้องการบันทึกสมาชิก รับซื้อ ขายออก สต็อก ค่าใช้จ่าย และรายงานกำไรขาดทุนในโปรแกรมเดียว

คู่มือนี้เขียนสำหรับเจ้าของจุดรับซื้อและพนักงานที่ใช้งานจริง ไม่ใช่คู่มือสำหรับนักพัฒนา

อ่านทีละงานบนเว็บได้ที่เมนู **คู่มือ** ในโปรแกรม หรือเปิดหน้า `/guide`

---

## 1. โปรแกรมนี้ทำอะไรได้

| งาน | ใช้เมนู |
| --- | --- |
| ดูภาพรวมวันนี้ | แดชบอร์ด |
| ตั้งประเภทสินค้า และดูสต็อกคงเหลือ | สต็อกสินค้า |
| รับซื้อยางจากสมาชิก พิมพ์สลิป | รับซื้อยาง |
| ขายยางให้บริษัทปลายทาง | ขายสินค้า |
| ค้นหาและพิมพ์สลิปย้อนหลัง | ประวัติการรับซื้อ |
| เก็บข้อมูลชาวสวน | สมาชิก |
| เก็บข้อมูลผู้รับซื้อปลายทาง | บริษัทปลายทาง |
| บันทึกค่าน้ำมัน ค่าซ่อม ค่าคนงาน | ค่าใช้จ่าย |
| สรุปซื้อ ขาย ค่าใช้จ่าย กำไรขาดทุน | รายงาน |
| ตั้งค่าใบเสร็จ ผู้ใช้ สำรองข้อมูล ใบอนุญาต | ตั้งค่าระบบ (ไอคอนชื่อผู้ใช้มุมล่างซ้าย) |

ข้อมูลของเวอร์ชันติดตั้งบนคอมพิวเตอร์เก็บไว้ในเครื่องนั้น ใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต หลังจากเปิดใช้งานใบอนุญาตแล้ว

## 2. เริ่มใช้งานครั้งแรก

### 2.1 ติดตั้งโปรแกรม

**Windows**

1. เปิดไฟล์ติดตั้งที่ได้รับจากผู้ขาย (ตัวติดตั้งชื่อ Yang Dee)
2. เลือกโฟลเดอร์ติดตั้ง ถ้าต้องการเปลี่ยนจากค่าเริ่มต้น
3. ติดตั้งให้ครบ แล้วเปิดจากไอคอน **Yang Dee** บนเดสก์ท็อปหรือเมนู Start

**macOS**

1. เปิดไฟล์ `.dmg` ที่ได้รับ
2. ลาก Yang Dee ไปที่โฟลเดอร์ Applications
3. เปิดโปรแกรมจาก Applications

ครั้งแรกที่เปิด ระบบจะพาไปหน้า **เปิดใช้งานระบบ**

### 2.2 ใส่ License Key

1. กรอก License Key ที่ได้รับตอนซื้อ
2. กดยืนยัน
3. ถ้าถูกต้อง หน้าจอจะขึ้น **เปิดใช้งานสำเร็จ** พร้อมวันหมดอายุ
4. กดไปหน้าเข้าสู่ระบบ

เก็บ License Key ไว้ในที่ปลอดภัย ใช้ตอนย้ายเครื่องหรือติดตั้งใหม่ ดูสถานะใบอนุญาตได้ที่ **ตั้งค่าระบบ → ใบอนุญาตซอฟต์แวร์**

### 2.3 เข้าสู่ระบบครั้งแรก

บัญชีเริ่มต้นที่มากับโปรแกรม:

- ชื่อผู้ใช้: `admin`
- รหัสผ่าน: `admin123`

หลังเข้าได้ครั้งแรก ให้สร้างบัญชีของเจ้าของจริง แล้วเลิกใช้รหัสผ่านเริ่มต้นนี้ (ดูหัวข้อ 12.3)

กดไอคอนดวงจันทร์หรือดวงอาทิตย์ที่มุมจอ เพื่อสลับโหมดสว่างและโหมดมืด

### 2.4 ออกจากระบบ

กดปุ่มออกจากระบบที่แถบด้านซ้ายล่าง อย่าปิดโปรแกรมทั้งวันโดยไม่สำรองข้อมูล ถ้ายังไม่ได้เปิดสำรองอัตโนมัติ

## 3. หน้าจอและสิทธิ์ผู้ใช้

เมนูอยู่แถบซ้าย

- คอมพิวเตอร์: กดปุ่มย่อเมนูได้ เหลือแต่ไอคอน
- แท็บเล็ตและมือถือ: กดปุ่มเมนูเพื่อเปิดแถบ แล้วกด Esc หรือกดนอกแถบเพื่อปิด

### สิทธิ์ที่มีในระบบ

| บทบาทบนหน้าจอ | ใช้ทำอะไร |
| --- | --- |
| เจ้าของ | ใช้ได้ทุกเมนู รวมตั้งค่า ผู้ใช้ สำรองข้อมูล และลบรายการรับซื้อ |
| ผู้จัดการ | ทำงานประจำวันได้ รวมแก้ประเภทสินค้า |
| พนักงาน | บันทึกงานประจำวันตามเมนูที่เห็น |
| บัญชี | เห็นเฉพาะเมนู **รายงาน** เหมาะกับคนที่มาดูตัวเลขอย่างเดียว |
| ผู้ดูแล | บัญชีภายในของผู้ติดตั้ง ไม่ได้สร้างจากหน้าจอ |

บัญชี **บัญชี** จะเข้าโปรแกรมแล้วไปที่หน้ารายงานทันที เมนูอื่นไม่แสดง

การลบรายการรับซื้อทำได้เฉพาะเจ้าของ (และผู้ดูแล) ถ้าพนักงานกดลบ ระบบจะแจ้งว่าไม่มีสิทธิ์

## 4. ลำดับที่ควรตั้งก่อนเปิดรับซื้อ

ทำตามลำดับนี้วันแรก แล้วงานประจำวันจะสั้นลง

1. **ตั้งค่าระบบ → ใบรับซื้อ (Slip)** ใส่ชื่อจุดรับซื้อ ที่อยู่ เลขประจำตัวผู้เสียภาษี และข้อความท้ายสลิป
2. **สต็อกสินค้า** เพิ่มประเภทสินค้าที่จะรับ เช่น น้ำยางสด ยางแผ่น เศษยาง
3. **สมาชิก** เพิ่มชาวสวนที่จะมาขายวันนี้
4. **บริษัทปลายทาง** เพิ่มโรงงานหรือผู้รับซื้อที่จุดรับซื้อขายต่อ
5. **ตั้งค่าระบบ → ผู้ใช้งาน** สร้างบัญชีให้พนักงานแต่ละคน อย่าใช้บัญชีเจ้าของร่วมกัน
6. **ตั้งค่าระบบ → สำรองข้อมูล** เปิดสำรองอัตโนมัติ

## 5. สต็อกสินค้าและประเภทสินค้า

เมนู **สต็อกสินค้า** เป็นทั้งรายการสินค้าและยอดคงเหลือ

แต่ละแถวแสดง:

- รหัสสินค้า และชื่อสินค้า
- สต็อกคงเหลือ (กิโลกรัม)
- ราคาเฉลี่ยต้นทุนต่อกิโลกรัม มาจากยอดรับซื้อ
- ราคาขายเฉลี่ยต่อกิโลกรัม มาจากยอดขาย
- กำไรหรือขาดทุนของสินค้าที่ขายไปแล้ว

### เพิ่มประเภทสินค้า

1. กด **เพิ่มประเภทสินค้า**
2. กรอก **รหัสประเภท** เช่น `FRESH` หรือ `DRY` ระบบจะทำให้เป็นตัวพิมพ์ใหญ่
3. กรอกชื่อที่พนักงานอ่านออก เช่น น้ำยางสด
4. กรอกคำอธิบายถ้าต้องการ
5. กด **เพิ่มประเภทสินค้า**

เพิ่มได้สูงสุด 50 ประเภท เมื่อครบ ปุ่มจะขึ้นว่าครบจำนวนสูงสุด

### ปิดรับซื้อชั่วคราว หรือลบ

- **ปิดใช้งาน** ใช้เมื่อเลิกรับประเภทนั้นชั่วคราว ประวัติเดิมยังอยู่ และเปิดกลับมาได้
- **ลบ** ถ้าประเภทนั้นมีประวัติรับซื้อ การขาย หรือสต็อกอยู่แล้ว ระบบจะไม่ลบจริง แต่จะปิดการใช้งานแทน เพื่อไม่ให้รายงานเก่าหาย
- กด **ประวัติ** เพื่อดูความเคลื่อนไหวของสินค้านั้น

สต็อกเพิ่มเมื่อบันทึกรับซื้อ และลดเมื่อบันทึกการขาย อย่าแก้ตัวเลขสต็อกด้วยมือ

## 6. สมาชิก

เมนู **สมาชิก** เก็บข้อมูลคนที่นำยางมาขาย

### เพิ่มสมาชิก

1. กดเพิ่มสมาชิก
2. กรอก **ชื่อ-นามสกุล** (จำเป็น)
3. **รหัสสมาชิก** สร้างให้อัตโนมัติ แก้เองไม่ได้
4. กรอกเบอร์โทร เลขบัตรประชาชน 13 หลัก ที่อยู่ ตามที่มี
5. เลือกหรือพิมพ์ชื่อธนาคาร แล้วกรอกเลขบัญชี เป็นตัวเลข ไม่เกิน 15 หลัก
6. กด **เพิ่มสมาชิก**

เบอร์โทร เลขบัตร และเลขบัญชี ระบบรับเฉพาะตัวเลข

### ใช้งานภายหลัง

- ค้นหาจากช่องค้นหาด้านบน
- กดแก้ไขเมื่อย้ายบัญชีหรือเปลี่ยนเบอร์
- เปิดประวัติการรับซื้อของสมาชิกคนนั้น เพื่อดูว่าขายมาเท่าไรในช่วงที่เลือก

ใส่สมาชิกก่อนรับซื้อ ตอนรับซื้อจะค้นจากชื่อหรือรหัสได้ทันที

## 7. รับซื้อยาง

เมนู **รับซื้อยาง** คือหน้างานหลักของจุดรับซื้อ บันทึกทีละรายการลงตะกร้า แล้วกดบันทึกครั้งเดียวเมื่อครบคัน หรือครบชุดของสมาชิกคนนั้น

### 7.1 กรอกรายการรับซื้อ

ช่องที่มีดอกจันเป็นช่องบังคับ

1. **วันที่รับซื้อ** ค่าเริ่มต้นคือวันนี้ เปลี่ยนได้ถ้าบันทึกย้อนหลัง
2. **สมาชิก** พิมพ์ชื่อหรือรหัส แล้วเลือกจากรายการ ลูกศรลงใช้เลือกในรายการได้
3. **ประเภทสินค้า** พิมพ์ชื่อหรือรหัสแล้วเลือก ถ้ายังไม่มีประเภทนี้ ให้ไปเพิ่มที่สต็อกสินค้าก่อน
4. **น้ำหนักรวมภาชนะ** น้ำหนักที่ชั่งได้ทั้งถังหรือทั้งตะกร้า หน่วยกิโลกรัม
5. **น้ำหนักภาชนะ** น้ำหนักถังเปล่า ใส่ 0 ได้ถ้าชั่งสุทธิมาแล้ว
6. **น้ำหนักสุทธิ** ระบบคำนวณให้ เป็นน้ำหนักรวมภาชนะลบน้ำหนักภาชนะ แก้เองไม่ได้
7. **ราคาต่อหน่วย** บาทต่อกิโลกรัม ถ้าสินค้านี้เคยรับซื้อ ระบบจะโชว์ราคาล่าสุด กดที่ปุ่มราคานั้นเพื่อใส่ให้เลย
8. **ยอดเงินรวม** คำนวณจากน้ำหนักสุทธิคูณราคาต่อหน่วย

กด **เพิ่มลงตะกร้า** ฟอร์มจะพร้อมรับรายการถัดไปของคนเดิมหรือคนถัดไป

กด Enter เพื่อเลื่อนไปช่องถัดไป โดยไม่ต้องใช้เมาส์ตลอดเวลา

กด **รีเซ็ต** เมื่อกรอกผิดและอยากเริ่มแถวนั้นใหม่

### 7.2 ค่าบริการในบิลเดียวกัน

ใช้เมื่อต้องเก็บค่าบริการพร้อมบิลรับซื้อ เช่น ค่าชั่ง หรือค่าขนส่งหน้าจุด

- บนคอมพิวเตอร์ การ์ด **บันทึกค่าบริการ** อยู่ด้านล่างฟอร์มรับซื้อ
- บนมือถือ สลับแท็บ **รับซื้อ** กับ **ค่าบริการ**

กรอกประเภทและจำนวนเงิน แล้วเพิ่มลงตะกร้าเหมือนรายการรับซื้อ

### 7.3 บันทึกจริง

รายการในตะกร้ายังไม่เข้าระบบ จนกว่าจะกด **บันทึกข้อมูล**

ตรวจน้ำหนัก ราคา และชื่อสมาชิกก่อนกดบันทึก เมื่อบันทึกแล้ว สต็อกของประเภทสินค้านั้นจะเพิ่มขึ้น และรายการไปโผล่ที่ประวัติการรับซื้อกับแดชบอร์ด

## 8. ประวัติการรับซื้อและพิมพ์สลิป

เมนู **ประวัติการรับซื้อ** ใช้ค้นบิลเก่า

ค้นได้จากเลขที่รับซื้อ ชื่อสมาชิก หรือรหัสสมาชิก

- กด **พิมพ์** เพื่อพิมพ์สลิปอีกครั้ง รูปแบบขึ้นกับที่ตั้งไว้ในตั้งค่าใบรับซื้อ
- กด **ลบ** ได้เฉพาะบัญชีเจ้าของ ระบบจะถามยืนยันก่อนลบ การลบมีผลกับสต็อกและรายงาน ใช้เมื่อบันทึกผิดเท่านั้น

---

## 9. ขายสินค้า

เมนู **ขายสินค้า** ใช้ตอนขายยางออกจากจุดรับซื้อไปบริษัทหรือโรงงาน สต็อกจะลดตามน้ำหนักที่ขาย

### กรอกการขาย

1. **วันที่**
2. **บริษัทปลายทาง** ค้นชื่อแล้วเลือก ถ้ายังไม่มี ให้ไปเพิ่มที่เมนูบริษัทปลายทางก่อน
3. **รูปแบบการขาย** เลือกอย่างใดอย่างหนึ่ง
   - จ่ายสด
   - ขายล่วง
   - ฝาก
4. **ประเภทสินค้า** เลือกจากสินค้าที่มีในสต็อก
5. **%ยาง** กรอกเมื่อต้องระบุเปอร์เซ็นต์เนื้อยางของล็อตที่ขาย
6. **น้ำหนัก (กก.)** ระบบแสดงสต็อกคงเหลือของประเภทนั้น ให้ขายไม่เกินยอดคงเหลือ
7. **ราคา/กก.** ระบบแสดงต้นทุนเฉลี่ยไว้ให้เทียบก่อนตั้งราคาขาย
8. **ค่าใช้จ่ายของการขาย** ใส่ได้สูงสุด 4 รายการ ชนิดที่มีให้เลือกคือ ค่าขนส่ง ค่าแรง ค่าบริการ ภาษี และอื่นๆ พร้อมจำนวนเงินและหมายเหตุ

ตรวจยอดรวมและกำไรที่โปรแกรมคำนวณให้ แล้วกดบันทึก

ถ้าต้องแก้บิลขายที่บันทึกไปแล้ว เปิดรายการนั้นจากตารางด้านล่าง แก้แล้วบันทึก หรือกดยกเลิกการแก้ไขถ้ายังไม่ต้องการเปลี่ยน

## 10. บริษัทปลายทาง

เมนู **บริษัทปลายทาง** เก็บโรงงานหรือผู้รับซื้อที่จุดรับซื้อขายยางให้

เพิ่มอย่างน้อยชื่อบริษัท รหัสสร้างให้อัตโนมัติ กรอกเบอร์โทรและที่อยู่ได้ตามที่มี แล้วจึงไปเลือกชื่อนี้ในหน้าขายสินค้า

---

## 11. ค่าใช้จ่าย

เมนู **ค่าใช้จ่าย** ใช้กับรายจ่ายของจุดรับซื้อที่ไม่ได้ผูกกับบิลขายรายใบ เช่น ค่าน้ำมันรถ ค่าซ่อมรถ ค่าคนงาน

หมวดที่ระบบเตรียมไว้:

- ค่าน้ำมัน
- ค่าซ่อมรถ
- ค่าคนงาน
- อื่นๆ

พิมพ์หมวดเองได้ ระบบจะแนะนำจากหมวดที่เคยใช้

แต่ละรายการมีวันที่และเวลา จำนวนเงิน และรายละเอียด ยอดนี้ไปโผล่ในรายงานค่าใช้จ่ายและรายงานกำไรขาดทุน

ค่าใช้จ่ายที่เกิดตอนขายล็อตนั้นๆ ให้ใส่ในหน้า **ขายสินค้า** จะได้หักจากล็อตนั้นตรงๆ

## 12. รายงาน

เมนู **รายงาน** มี 5 แท็บ

| แท็บ | ใช้เมื่อ |
| --- | --- |
| สรุปการรับซื้อ | ดูว่าช่วงนี้รับซื้อประเภทไหน น้ำหนักเท่าไร เป็นเงินเท่าไร |
| สรุปการขาย | ดูยอดขายออกตามช่วงวันที่ |
| สรุปรายสมาชิก | ดูว่าสมาชิกแต่ละคนขายยางเข้ามาเท่าไร |
| ค่าใช้จ่าย | ดูรายจ่ายตามหมวด |
| กำไร/ขาดทุน | ดูผลประกอบการในช่วงที่เลือก เป็นตารางและกราฟ |

### วิธีออกรายงาน

1. เลือกแท็บ
2. กำหนดวันเริ่มและวันสิ้นสุด
3. ในแท็บรับซื้อหรือขาย เลือกกลุ่มรายงานได้ ถ้าต้องการรวมหลายประเภทสินค้าเป็นกลุ่มเดียว กด **จัดการกลุ่มรายงาน**
4. กด **สร้างรายงาน**
5. กด **ดาวน์โหลด PDF** เมื่อต้องพิมพ์หรือส่งให้บัญชี

แท็บกำไรขาดทุนเลือกดูรายเดือนหรือรายวันในช่วงที่กำหนดได้ ตัวเลขสีเขียวคือกำไร สีแดงคือขาดทุน

รายงานกำไรขาดทุนใช้ข้อมูลรับซื้อ การขาย และค่าใช้จ่ายที่บันทึกจริง ถ้าวันนั้นยังไม่บันทึกค่าใช้จ่าย กำไรจะสูงกว่าความเป็นจริง

## 13. แดชบอร์ด

เมนู **แดชบอร์ด** เป็นหน้าแรกหลังเข้าสู่ระบบ (ยกเว้นบัญชีบทบาทบัญชี)

ใช้ดูของวันนี้แบบเร็ว:

- จำนวนและยอดรับซื้อวันนี้ แยกตามประเภทสินค้า
- น้ำหนักที่รับวันนี้
- รายการรับซื้อล่าสุด
- รายการขายล่าสุด
- ค่าใช้จ่ายล่าสุด
- สมาชิกที่มียอดสูง

ใช้ตรวจว่าบันทึกครบหรือยังก่อนปิดจุด ไม่ใช้แทนรายงานตอนปิดเดือน

## 14. ตั้งค่าระบบ

กดชื่อผู้ใช้มุมล่างซ้าย หรือไอคอนตัวอักษรย่อ แล้วเข้า **ตั้งค่าระบบ**

### 14.1 ใบรับซื้อ (Slip)

ตั้งค่าก่อนพิมพ์สลิปจริงให้ลูกค้า

- ชื่อจุดรับซื้อ
- ที่อยู่
- เลขประจำตัวผู้เสียภาษี
- ข้อความท้ายสลิป
- ขนาดตัวอักษรบนสลิป: เล็ก ปานกลาง ใหญ่ ใหญ่มาก
- รูปแบบสลิป
  - **สลิป** ใบมาตรฐาน
  - **สลิปมีลายเซ็น** มีช่องผู้รับเงินและผู้จ่ายเงิน
  - **ใบ A4** สำหรับเครื่องพิมพ์กระดาษ A4
- ความกว้างกระดาษความร้อน: 58 มม. (เครื่องพิมพ์ความร้อนเล็ก), 80 มม. (เครื่องพิมพ์ความร้อนมาตรฐาน), 104 มม. (กระดาษกว้าง)

ดูตัวอย่างก่อนกด **บันทึกการเปลี่ยนแปลง** ตัวอย่างอัปเดตทันที แต่ข้อความบนใบจริงเปลี่ยนเมื่อบันทึกแล้ว แล้วพิมพ์ทดสอบหนึ่งใบกับเครื่องพิมพ์จริง

### 14.2 การแสดงผล

ปรับตัวอักษรและสีพื้นหลังทั้งโปรแกรมบนเครื่องนี้ มีผลทันที ไม่ต้องบันทึกแยก

- ขนาด: เล็ก ปกติ ใหญ่ ใหญ่มาก
- รูปแบบตัวอักษร: ค่าเริ่มต้น, Sarabun, Noto Sans Thai, Prompt, Kanit
- พื้นหลังโหมดสว่าง: ขาวอมเทา, ครีมอ่อน, เทาอ่อน
- พื้นหลังโหมดมืด: ถ่านเข้ม, ดำสนิท, ถ่านอุ่น

การตั้งค่านี้ผูกกับเครื่อง ไม่ได้ตามบัญชีผู้ใช้

### 14.3 ผู้ใช้งาน

ให้เจ้าของเป็นคนสร้างบัญชี

1. กดเพิ่มผู้ใช้
2. ตั้งชื่อผู้ใช้และรหัสผ่านที่เดายาก
3. เลือกบทบาท: พนักงาน ผู้จัดการ บัญชี หรือเจ้าของ
4. บันทึก แล้วบอกชื่อผู้ใช้กับรหัสผ่านให้คนนั้นโดยตรง

แนวทางที่ใช้กัน:

- เจ้าของ 1 บัญชี สำหรับตั้งค่า ลบรายการ และดูใบอนุญาต
- พนักงานหน้าร้าน คนละบัญชี จะได้รู้ว่าใครเป็นคนบันทึก
- บัญชีอีก 1 บัญชี ถ้ามีคนมาดูรายงานอย่างเดียว

ปิดผู้ใช้ที่ลาออก แทนการลบทิ้ง จะได้ไม่ทำให้ประวัติเก่าขาดชื่อ

### 14.4 ประวัติการใช้งาน

ใช้ตรวจว่าใครเข้าโปรแกรมและทำรายการสำคัญเมื่อไร ใช้ตอนตามบิลที่ผิดหรือสงสัยว่ามีคนแก้ข้อมูล

### 14.5 การเชื่อมต่อ

โปรแกรมบนเครื่องหลักทำงานเป็น **โหมดเซิร์ฟเวอร์** ข้อมูลอยู่ที่เครื่องนี้

ในแท็บนี้จะมี Server URL รูปแบบ `http://เลขไอพีเครื่อง:3000` กดคัดลอกแล้วใช้บนเครื่องอื่นในวงแลนเดียวกัน เมื่อต้องการเปิดดูหรือคีย์จากอีกเครื่อง

เครื่องหลักต้องเปิดโปรแกรมค้างไว้ เครื่องอื่นถึงจะเชื่อมต่อได้ ดูสถานะโหมดที่มุมขวาบน เป็นจุดสีเขียวเมื่อเป็นเซิร์ฟเวอร์

### 14.6 สำรองข้อมูล

ข้อมูลอยู่ที่เครื่อง ถ้าฮาร์ดดิสก์เสียและไม่มีการสำรอง บิลเก่ากู้คืนไม่ได้

ทำสองอย่าง:

1. กด **สำรองข้อมูลตอนนี้** อย่างน้อยวันละครั้งช่วงแรก แล้วนำไฟล์ไปเก็บไว้นอกเครื่อง เช่น แฟลชไดรฟ์หรือคอมพิวเตอร์อีกเครื่อง
2. เปิด **สำรองอัตโนมัติ** แล้วเลือกความถี่
   - ทุกวัน
   - ทุกสัปดาห์ เลือกวัน
   - ทุกเดือน เลือกวันที่
   ตั้งเวลาที่จุดรับซื้อยังเปิดเครื่องอยู่ เช่น 22:00

จากรายการประวัติสำรอง สามารถดาวน์โหลดหรือกู้คืนได้ การกู้คืนจะแทนที่ข้อมูลปัจจุบันทั้งชุด ใช้เมื่อข้อมูลปัจจุบันเสียเท่านั้น และควรสำรองก้อนล่าสุดไว้ก่อนกู้คืน

### 14.7 ใบอนุญาตซอฟต์แวร์

ดูวันหมดอายุและสถานะใบอนุญาต ต่ออายุก่อนหมดเขตตามที่ตกลงกับผู้ขาย ถ้าใบอนุญาตหมด โปรแกรมจะเข้าใช้งานต่อไม่ได้จนกว่าจะใส่คีย์ที่ยังไม่หมดอายุ

## 15. งานหนึ่งวัน ของจุดรับซื้อ

**ก่อนเปิดรับ**

1. เปิด Yang Dee แล้วเข้าด้วยบัญชีของตัวเอง
2. เปิดแดชบอร์ดดูว่าเป็นวันใหม่ ยอดวันนี้เริ่มจากศูนย์
3. ถ้ามีสมาชิกใหม่หรือประเภทสินค้าใหม่ เพิ่มให้ครบก่อนชั่ง

**ระหว่างวัน**

1. รับซื้อที่เมนูรับซื้อยาง ใส่ตะกร้าให้ครบคัน แล้วกดบันทึกข้อมูล
2. พิมพ์สลิปให้ชาวสวน
3. เมื่อมีรถออกไปขาย บันทึกที่เมนูขายสินค้า พร้อมค่าขนส่งของเที่ยวนั้น
4. มีใบเสร็จน้ำมันหรือค่าซ่อม เมื่อไร บันทึกที่เมนูค่าใช้จ่ายทันที

**ก่อนปิด**

1. เปิดประวัติการรับซื้อของวันนี้ เทียบกับสลิปที่พิมพ์ออกไป
2. เปิดแดชบอร์ดดูยอดรับซื้อกับค่าใช้จ่ายวันนี้
3. ถ้ายังไม่ได้เปิดสำรองอัตโนมัติ กดสำรองข้อมูลตอนนี้
4. ออกจากระบบ

**ปิดสัปดาห์หรือปิดเดือน**

1. ออกรายงานสรุปการรับซื้อ สรุปการขาย ค่าใช้จ่าย และกำไรขาดทุน ตามช่วงวันที่
2. ดาวน์โหลด PDF เก็บไว้
3. คัดลอกไฟล์สำรองไปไว้นอกเครื่องอย่างน้อยหนึ่งชุด

## 16. ปัญหาที่พบบ่อย

**เปิดโปรแกรมแล้วขึ้นหน้าเปิดใช้งานระบบ**

ยังไม่ได้ใส่ License Key หรือคีย์หมดอายุ ใส่คีย์ที่ผู้ขายให้ แล้วตรวจวันหมดอายุในตั้งค่า

**เข้าไม่ได้**

ตรวจตัวพิมพ์เล็กใหญ่ของชื่อผู้ใช้และรหัสผ่าน ถ้าลืมรหัสของพนักงาน ให้เจ้าของเข้าไปตั้งรหัสใหม่ที่ผู้ใช้งาน ถ้ารหัสเจ้าของเริ่มต้นยังไม่ถูกเปลี่ยน ใช้ `admin` และ `admin123`

**ค้นสมาชิกไม่เจอ**

สมาชิกยังไม่ได้ถูกเพิ่ม หรือพิมพ์คนละชื่อกับที่บันทึกไว้ ไปเพิ่มที่เมนูสมาชิกก่อน แล้วกลับมารับซื้อ

**ไม่มีประเภทสินค้าให้เลือก**

ยังไม่ได้สร้างที่สต็อกสินค้า หรือประเภทนั้นถูกปิดใช้งาน เปิดใช้งานกลับได้จากปุ่มในแถวนั้น

**น้ำหนักสุทธิไม่ตรง**

น้ำหนักสุทธิคือน้ำหนักรวมภาชนะลบน้ำหนักภาชนะ ตรวจว่าใส่ภาชนะถูกช่อง ถ้าชั่งน้ำหนักสุทธิมาแล้ว ให้ใส่น้ำหนักนั้นในช่องน้ำหนักรวมภาชนะ และใส่ภาชนะเป็น 0

**ขายไม่ได้เพราะน้ำหนักเกิน**

สต็อกของประเภทนั้นไม่พอ ตรวจว่าบันทึกรับซื้อครบหรือยัง และไม่ได้เลือกประเภทสินค้าผิด

**พิมพ์สลิปแล้วตัวเล็กหรือกว้างไม่พอดี**

ไปที่ตั้งค่าใบรับซื้อ เปลี่ยนขนาดตัวอักษรและความกว้างกระดาษให้ตรงกับม้วนที่ใส่ในเครื่องพิมพ์ แล้วพิมพ์ทดสอบ

**เครื่องอื่นในร้านเปิดไม่เห็นข้อมูล**

เครื่องหลักต้องเปิด Yang Dee ค้างไว้ และทั้งสองเครื่องต้องอยู่ในวงแลนเดียวกัน ใช้ Server URL จากแท็บการเชื่อมต่อของเครื่องหลัก

**บัญชีเข้ามาแล้วเห็นแต่รายงาน**

บัญชีนั้นถูกตั้งบทบาทเป็น **บัญชี** ซึ่งตั้งใจให้ดูรายงานอย่างเดียว ถ้าต้องรับซื้อ ให้เจ้าของเปลี่ยนบทบาทเป็นพนักงานหรือผู้จัดการ

**กดลบรายการรับซื้อไม่ได้**

เฉพาะเจ้าของลบได้ ให้เจ้าของตรวจบิลแล้วลบเอง

**กลัวข้อมูลหาย**

เปิดสำรองอัตโนมัติ และคัดลอกไฟล์สำรองออกนอกเครื่องเป็นประจำ การสำรองที่อยู่ในเครื่องเดียวกับโปรแกรม ช่วยไม่ได้ถ้าเครื่องทั้งเครื่องเสีย

## 17. สิ่งที่ไม่ควรทำ

- ไม่ใช้บัญชีเจ้าของร่วมกันทั้งร้าน
- ไม่ลบบิลที่บันทึกถูกแล้ว เพื่อแก้ตัวเลขทีหลัง ถ้าต้องแก้ ให้ตรวจผลกระทบต่อสต็อกก่อน
- ไม่ปิดประเภทสินค้าแทนการดูรายงานเก่า การปิดมีผลกับการรับซื้อใหม่เท่านั้น
- ไม่กู้คืนไฟล์สำรองเก่าทับงานวันนี้ โดยยังไม่ได้สำรองก้อนปัจจุบันไว้ก่อน
- ไม่พิมพ์รหัสผ่านเริ่มต้น `admin123` ติดไว้ที่เครื่องหลังเริ่มใช้งานจริง
